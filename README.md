# 📻 BV号监听器

> Bilibili 直播BV 号实时监控工具

**v1.4.4**

---

## 📌 简介

BV号监听器是一款修改自5050-SC_Monitor的专为 Bilibili 直播间设计的桌面端监控工具。它实时连接指定直播间，自动捕获观众发送的 SC（醒目留言）和弹幕消息，从中智能提取 BV 号，并一键跳转到对应视频页面。同时支持视频信息查询、用户头像显示、上舰用户标识、黑名单管理等功能。

---

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🔗 BV号自动提取 | 从 SC 和弹幕消息中自动识别 BV 号（如 BV1xx411x7xx），支持带干扰字符的场景，提取后显示在 BV号列。 |
| 🚀 一键跳转 | 点击 BV号列即可复制并在浏览器中打开对应视频页面，再次点击可取消标记。已点击的行会高亮显示。 |
| 📊 视频信息查询 | 自动获取 BV 对应视频的标题、标签、播放量、点赞、投币、收藏数据，鼠标悬停在 BV号列即可查看。 |
| 👤 用户头像显示 | 在用户列显示圆形头像，支持本地缓存，下次启动直接从本地加载，加快显示速度。 |
| 🎨 上舰用户颜色标识 | 舰长蓝色、提督紫色、总督红色文字，SC 粉色文字+粉色背景，特殊 UID 用户红色加粗，一目了然。 |
| 📲 扫码登录 | 支持 Bilibili APP 扫码登录自动获取 SESSDATA，无需手动从浏览器复制 Cookie。 |
| 🚫 黑名单管理 | 支持按 UID 屏蔽用户，支持关键词屏蔽（含弹幕和视频标题）右键即可操作。 |
| 🔍 显示模式切换 | 三种模式轮换：所有弹幕 → 仅显示SC → 仅上舰SC，一键切换。支持仅显示有 BV号的消息。 |
| 💾 SC 数据库 | 所有 SC 记录自动存入 SQLite 数据库，记录用户累计 SC 次数和金额，悬停即可查看统计。 |
| 📝 SC 日志 | 每条 SC 和弹幕自动写入 JSONL 日志文件，方便后续分析和审计。 |
| 📌 窗口置顶 | 支持一键置顶窗口，保持在最前，不遮挡其他操作。 |
| 📐 窗口记忆 | 窗口大小可自由调整，自动保存到配置文件，下次启动恢复。最小尺寸锁定 1085×650。 |

## 🖱️ 右键菜单

在消息列表中右键点击任意行，弹出以下菜单：

- **📋 复制内容** — 复制该条消息文本到剪贴板
- **🔗 复制 BV 号** — 复制 BV 号到剪贴板
- ---
- **🚫 屏蔽此用户** — 将该用户加入黑名单，移除其所有消息
- **🗑️ 删除消息** — 从列表中删除该条消息

## 🚀 快速上手

1. **启动程序**
   双击 `BV号监听器.exe` 运行。首次启动使用空 SESSDATA，可监听公开直播间。

2. **登录 Bilibili（可选）**
   点击「📱 扫码登录」，使用 Bilibili APP 扫码完成登录，自动获取 SESSDATA。或点击「🔑 Cookie」手动输入。

3. **设置直播间号**
   点击「🏠 直播间」，输入要监听的直播间号，保存后重启程序生效。

4. **实时监控**
   程序自动连接直播间，SC 和弹幕实时显示在列表中。BV 号自动提取并显示。

5. **点击跳转**
   点击 BV号列直接在浏览器打开视频。鼠标悬停查看视频标题、播放量等详细信息和投稿人统计。

6. **管理黑名单**
   右键「屏蔽此用户」或通过工具栏「🚫 黑名单」和「🔤 屏蔽关键词」管理过滤规则。

## ⚙️ 配置文件

程序运行时自动生成 `sc_config.json` 配置文件，包含以下主要配置项：

```json
// 核心配置
"直播间ID": 5050,
"SESSDATA": "",
"显示模式": "all",       // all | sc_only | vip
"仅显示有BV号": false,

// 特殊用户
"特殊用户UID": [433351],

// 黑名单
"黑名单关键词": [],
"黑名单UID": [],
"黑名单用户信息": {},

// 窗口
"窗口宽度": 1085,
"窗口高度": 650
```

> **⚠️ 注意：** 修改直播间号或 SESSDATA 后需重启程序才能生效。其他设置（显示模式、黑名单等）即时生效。

## 💾 数据存储

| 文件/目录 | 说明 |
|-----------|------|
| `sc_config.json` | 主配置文件，保存所有设置 |
| `sc_monitor.log` | 运行日志文件 |
| `data/sclog-*.jsonl` | SC 和弹幕消息日志（按时间命名） |
| `avatar_cache/` | 用户头像本地缓存目录（以 UID 命名的 PNG 文件） |
| `sc_data.db` | SQLite 数据库，存储 SC 历史记录和用户统计 |
